# 《面团》世界 V2：沙漠风格地形关卡

关卡：`/Game/Maps/DoughWorldV2/Levels/L_DoughWorldV2_Desert`

本次新建独立关卡。原有 CrumbFrontier、TopDown 示例关卡和 SoStylized 资产包均保留。内容目录中的新资源集中在 `Maps/DoughWorldV2`。

## 打开与使用

1. 在内容浏览器打开 `Content → Maps → DoughWorldV2 → Levels`，双击 `L_DoughWorldV2_Desert`。
2. 点击运行，再单击游戏视口。沿浅色地面路线从南侧出生点前往面粉、水源、战斗点及基地。
3. 使用原有 TopDown 的鼠标点击移动；空格跳跃，Shift 沿角色朝向翻滚。Shift+F1 释放鼠标，Esc 结束运行。
4. 修改地形：Shift+2 进入地形模式，选中 `Terrain_500m_EditableLandscape` 后雕刻。它是原生 Landscape，不是平面模型。
5. 修改植被：Shift+3 进入植被模式。选择 `Maps/DoughWorldV2/Foliage` 中的类型即可继续刷草、灌木、棕榈或仙人掌；Shift 配合植被刷用于擦除。请先保存副本再大范围修改。

## 已搭建的内容

- 约 500×500 米、505×505 采样点的可编辑地形，含基地高地、浅层沙地、发酵高地、酵母生态区、霉菌凹地和世界深层盆地。
- SoStylized 砂岩峭壁、石柱、层状岩、散石、沙漠植物、棕榈和瀑布模型。草丛使用区域颜色，无需 RVT。
- 五处建筑占位、十三个角色/怪物占位、四类资源点、六组指定植被地标、四个孔洞地貌和三个独立机关占位。气孔近道机关与气孔实体共用一个位置。
- 黄油瀑布上游、岩岸、下游潭面和通往入口的浅溪。瀑布目前采用简化景观表现。
- 九个教程路线锚点、玩家出生点、光照、雾和覆盖全图的导航范围。

资产包中没有面团世界专用的建筑、人物或菌类角色，因此这些内容使用可替换的简单占位件；酵母生态区另补了六组大型蘑菇轮廓，帮助区分区域。

## 数据坐标与高度

以 JSON 的 `pos/center` 米制坐标为准。`pixel_to_meter` 不再重复应用。

```
UE X = (JSON x - 250) × 100 厘米
UE Y = (JSON y - 250) × 100 厘米
地图上方对应 UE -Y
```

`elevation_value` 是相对高度参考，不是米数。区域基础高度以 `(elevation_value - 140) × 0.4 米` 转换，再进行边缘过渡、沙丘起伏、路线坡道和点位整平。局部瀑布高度经过调整，使下游潭面高于入口浅溪，避免逆流。实际地形数据保存在 `Source/terrain_data.json` 和 `DoughWorld_505.r16`。

同中心的基地与浅层区域按嵌套处理。参考图钉不当作实际场景点位；祭坛采用建筑数据坐标，未采用概念图图钉坐标。

## 程序对接

这一阶段只搭建环境与占位，不新增游戏机制。角色 AI、战斗、掉落、采集、形态转换、冲撞破壁、压力板、呼吸孔计时、深渊传送和 Boss 逻辑均未实现。机关开口保留可通行状态，尚未强制落实“唯一入口”的玩法封锁。

世界设置继续引用 `/Game/TopDown/Blueprints/BP_TopDownGameMode` 及现有玩家角色，本次没有改写玩家 C++、蓝图输入或全局启动地图。原有跳跃/翻滚继承使用。

主要占位 Actor 的标签保留 `SourceId=<JSON id>`，另带 `DoughWorldV2_Generated`。程序按 `SourceId` 查找对接点，避免依赖中文显示名或临时 Actor 编号。`demo_route_1` 至 `demo_route_9` 是 TargetPoint，运行时不显示编辑器图标。

环境大纲按 Terrain、Lighting、Environment、Buildings、Characters、Resources、FloraLandmarks、Holes、GatePlaceholders、ButterWaterfall、DemoRoute、Navigation 分组。角色、资源和路线标记关闭导航影响，避免占位模型产生无法到达的小导航岛。

正式角色/建筑可替换对应 Actor 或同文件夹内的组合件，保留其根位置、SourceId 和语义。孔洞目前是有底凹坑；以后接地下关卡或传送时再加入真正的 Landscape 可见性洞口与安全边界。

## 验证与当前限制

保存后重新打开关卡，复查得到 776 个 Actor、8,355 个原生植被实例；植被朝向正常，新资源未发现缺失依赖。16 个关键位置的 Landscape 碰撞高度与生成数据一致，最大偏差约 2.3 厘米。教程八段路线均能找到完整路径。运行中玩家正常出生、起跳约 1.18 米、落地，并走到第一处面粉点附近。

沿用的翻滚在面粉补给点附近的单次测试中只移动了约 2.8 厘米，尚未确认是角色动作对地形接触的处理还是该点的局部障碍造成。本次没有调整已有角色逻辑，不将翻滚计为通过验证。对应记录保留在 `action_report.json`，后续可针对该位置排查。

## 文件目录

- `Levels`：关卡。
- `Terrain`：无 RVT 沙地材质、区域色图及高度更新辅助资源。
- `Materials`：占位材质、黄油瀑布材质实例。
- `Foliage`：本关卡专用植被类型和区域草颜色。
- `Source`：输入 JSON、数值地形和高度图。
- `Documentation`：本说明、资产清单与验证记录。

交付目录中的生成脚本是制作记录，不是日常使用入口。场景已生成并保存，后续使用 Unreal 编辑器直接编辑；不要在已经手工修改的关卡上重复运行整图生成脚本。
