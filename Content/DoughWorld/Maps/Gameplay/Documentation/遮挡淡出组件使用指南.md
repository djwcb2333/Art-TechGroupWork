# 给自己的蓝图添加遮挡淡出

此功能的计算部分是 `Source/GDATtest/CameraOccluderFadeComponent.cpp`，已经包装成可在蓝图里添加的 Actor Component。使用它不需要编写或重新编译 C++。

## 普通建筑、树或障碍物蓝图

1. 打开自己的 Actor 蓝图。在组件面板点击“添加”，搜索 `Camera Occluder Fade` 并添加。
2. 选中需要变透明的 **Static Mesh 组件**，在详情的 **Component Tags** 添加 `CameraFade`。它是组件标签，不是整个 Actor 的 Tags。
3. 给需要淡出的材质槽设置兼容材质：材质中有名为 `CameraFade` 的 Scalar Parameter，默认值为 1，并真正参与 Opacity Mask/Opacity 计算。
4. 本工程现有参考材质为 `/Game/DoughWorld/Maps/DoughWorldDepth/Materials/M_DepthOrganic_Fade`。可先给测试物体用其材质实例确认接入，再在自己的材质副本里加入相同的淡出部分，以保留原来的贴图和美术外观。
5. 选中 Camera Occluder Fade 组件，保持 `Protect Player` 开启。编译并保存蓝图。运行时站到该物体后方，组件会检测当前摄像机到玩家的遮挡。

组件只管理**同一个 Actor** 中带该标签的普通 Static Mesh 组件。应把组件放在负责遮挡的建筑/树木蓝图上。屋顶、树冠最好是独立组件，便于只淡出它们；大型复杂建筑按需要拆分。

## 在自己的材质里接入

建议先复制母材质，避免批量影响原始素材。现有参考材质使用 Masked 和 DitherTemporalAA：

`ScalarParameter CameraFade（默认1） → DitherTemporalAA → 与原有透明遮罩相乘 → Opacity Mask`

若原材质没有透明遮罩，可以用常数 1 作为原遮罩。只创建同名参数、没有把它接到实际输出，不会产生视觉效果。多个材质槽分别检查；缺少参数的槽会被保留，并在日志提示。

## 常用参数

| 蓝图详情属性 | 默认 | 含义 |
|---|---:|---|
| Component Tag | CameraFade | 需要参与淡出的网格组件标签 |
| Parameter Name | CameraFade | 材质中的标量参数名称 |
| Protect Player | 开启 | 自动保护当前本地玩家的可见性 |
| Occluded Visibility | 0.2 | 遮挡时剩余可见度，0接近全透明，1完全可见 |
| Fade Out Seconds | 0.18秒 | 进入遮挡后的淡出时间 |
| Fade In Seconds | 0.3秒 | 离开遮挡后的恢复时间 |
| Clear Hold Seconds | 0.2秒 | 防止边缘反复闪烁的保持时间 |
| Scan Interval | 0.08秒 | 遮挡检测间隔 |
| Bounds Padding Cm | 10厘米 | 检测包围盒的扩张量 |
| Local Player Index | 0 | 本地玩家编号 |

## 蓝图节点

- `Refresh Fade Meshes`：游戏中更换模型、材质或组件标签后调用，重新绑定。
- `Add Protected Target`：除玩家外，还保护指定的交互目标。
- `Remove Protected Target` / `Clear Protected Targets`：移除附加目标。
- `Set Interaction Target For World`：在交互目标切换时更新本关卡所有淡出组件的附加保护目标；传空目标清除。仅在目标变化时调用。
- `Get Managed Mesh Count` / `Get Skipped Slot Count`：排查是否正确找到网格和兼容材质槽。
- `Evaluate Occlusion Now` / `Get Fade Status`：查看当前检测和各材质槽淡出状态。

## 当前边界

当前实现适用于普通 Static Mesh 组件。植被工具绘制的 ISM/HISM 实例会跳过，需要单独的实例实现。淡出不会修改碰撞；墙仍然挡路。它依赖运行时玩家摄像机，编辑器未游玩时不执行检测。恢复或移除组件时会还原其接管的原始材质。
