# 主菜单与可复用 UI 弹跳示例

本轮已直接集成至 `E:/Unreal Project/GDATtest/GDATtest.uproject`。源码和资产不需要再导入一次。

## 先运行

在内容浏览器打开 `Content/DoughWorld/Maps/Gameplay/Frontend/Levels/L_DWMainMenu_Showcase`，点击运行。

流程：黑幕 → YOUR TEAM 占位 Logo → 虚焦村庄背景与标题/按钮弹出 → 开始进入三槽存档界面。加载现有存档会进入原玩法地图。正式小组 Logo 和新增音效由你在槽位中替换。

## 三个主要修改入口

| 要修改什么 | 资产与位置 |
|---|---|
| 布局、Logo、开场时间轴、页面入场 | `Frontend/UI/WBP_DWFrontend`；设计器、动画，以及类默认值的 Frontend / UI Page Transitions |
| 背景镜头轻摆、切页时短暂轻晃 | `Frontend/Blueprints/BP_DWFrontendHUD` → 类默认值 → Frontend / Camera / Sway 与 Transition |
| 给任意控件加悬停、按压或手动弹跳 | 控件蓝图设计器中选中目标控件 → 详情 → 添加组件 → `DW UI Bounce` |

原玩法的背包、制作、暂停、设置等界面仍在 `Gameplay/UI/WBP_DWGameplay`。这些页面也继承通用入场效果。新的独立 WBP 需要自己播放入场，教程有步骤；不会自动影响项目中一切任意新建界面。

主菜单示例的三按钮和标题已装好 DW UI Bounce。因标题已有专用入场动画，这四处关闭了组件的 Play on Construct，以免叠加两次入场。一般新控件可以按需开启。
