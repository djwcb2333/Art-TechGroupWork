# 面团世界玩法原型：本轮交付与验证

工程：`E:/Unreal Project/GDATtest/GDATtest.uproject`，UE 5.8.2。

打开 `/Game/DoughWorld/Maps/Gameplay/Levels/L_DoughWorld_GameplayPrototype`，点击运行，再在标题页选择“开始游戏”→空槽“新建”或已有槽“加载”。本轮所有新玩法资源均在 `Content/DoughWorld/Maps/Gameplay`，是独立平面测试地图。

## 角色显示修复

- `BP_DWTopDownCharacter` 的 Mesh 旋转为 **Pitch 0、Yaw -90、Roll 0**。原错误将 -90 写到 Pitch，导致整个人侧躺；已修复并强制保存蓝图。
- `Characters/Hero/Materials/M_DoughHero` 使用角色包内原贴图，已启用 **Used with Skeletal Mesh** 并保存。角色身体、头巾、背包能够显示颜色。
- 待机、行走、攻击、变身、死亡均已接入并检查姿势。死亡动画本身会倒下，这是正常死亡表现。
- 没有独立冲刺动画时，空格保留短距离平移冲刺；没有跳跃、没有翻跟头。Shift 是持续疾跑。
- UMG 使用可序列化的字体资源，标题不再错误换行。相机支持暂停期间刷新视图。
