# Concept To Build：V1概念图到可用场景

**当前阶段是V1视觉候选，先看图并收集视觉反馈，再确定资产制作和搭建。UE场景尚未达到这些图中的效果。** 本文件只做资产与实现范围拆分，没有修改关卡、蓝图、材质或现有UI交接，也不提出采购要求。

本轮实际查看了 [整体预览](00_WorldOverview_V1.png)、[基地概念](01_Base_Concept.png) 和 [地下菌核概念](06_DeepCore_Concept.png)，其余区域按 [SceneBriefs](SceneBriefs.md) 与当前JSON约束整理，不将未查看的细图内容写成已确认事实。

这三张图共同提出的视觉候选是：奶油色多孔面团拱体、圆润主棚、木器与面包生活细节、青绿气泡/植被、紫金发光地下内腔。具体孔洞数量、拱门、高塔、烟囱、门扇、地下台阶和台地高度都是概念描绘，不自动成为新增实体或玩法需求。

## 从图到场景必须保留的边界

1. **原JSON管点位和路线，图管造型和气氛。** AI透视会压缩距离、合并景深、放大地标；不能直接从图片像素反推坐标、米制高差或房屋尺寸。当前依据是 [10_document.json](../Handoff/Originals/10_document.json) 和 [depth_supplement.json](../TerrainDesign/depth_supplement.json)。`elevation_value`是灰度参考，不是米。
2. **保持50个原节点和路线关系。** 图中反复出现的拱洞不能一律做成可通行隧道。发酵区的破壁入口与酵母高地的哨戒缝隙仍各是规定边界唯一通口；霉菌木桥仍是可选近道，外圈绕行保留。
3. **继续适配固定2.5D相机。** 当前玩法基准为俯角约−50°、Yaw45°、FOV55、SpringArm2800cm。概念图低机位、夸张广角、近景框景不直接替换玩法相机。先用现有相机检查玩家、路径、资源和交互面能否被看见。
4. **屋顶、上墙、菌盖/囊体上冠、洞顶必须分件。** 下墙/菌柄和地面保持稳定边界，高遮挡部分单独接现有渐隐逻辑。图中基地圆顶若采用，需要拆为可进入墙体、门洞和独立顶；不能把整栋房连同家具合并透明。
5. **暂不使用RVT。** 新地表/岩壁采用普通纹理、顶点色或遮罩混色等候选方案；地形接触效果不能把运行时虚拟纹理变成隐含依赖。
6. **所有新制作资源放进Content/Maps。** 建议新版本根 `/Game/Maps/DoughWorldDepth/ArtDirectionV1/`，下分 `Meshes`、`Materials`、`Textures`、`VFX`。这是拟定目录，不表示内容已创建。Fantastic现有网格继续依赖原包材质/贴图，不能只迁移网格副本。
7. 图里的门、锅、烟、气泡、发光菌核和人物姿态属于美术候选；不代表门交互、烹饪、资源采集、动态破壁、Boss、角色动画或物理机关已实现。

## 六场景的最小资产组合

下面的“最小”是做一个可判断方向的场景样板所需组合，并非整张世界的最终资产数量。网格族可以由少量基础件变形组合，先不按概念图每个细节各建一件。

### 01 基地

- **复用起点：** R01/R02 + F01/F02/F03/F04/F05；F06补给车为第二轮装饰。保持现有主棚、工作台、仓架三个设施各自的锚点。
- **需自建网格：** 1组圆顶主棚（独立顶、墙、门洞），2–3个奶油面团路缘/台缘模块，1个可独立处理的简洁棚布；图中烟囱、花盆、额外门扇先列为可选，避免第一轮扩展室内整套资产。
- **需自建/派生材质：** 奶油面团表面与切面各1个主方向；棚布1个实例。小凹孔优先纹理/法线，剪影大孔才用几何，避免把整个房体打成复杂穿孔网格。
- **VFX：** 首轮可以没有。方向确定后再加一套小烟囱轻烟；不引入烹饪系统。
- **落地核对：** 主棚(221.7,243.3)、工作台(221.7,266.7)、储物修复(196.7,256.7)不挪成图中构图位置；屋顶渐隐、门口和工作台操作面优先。图里较密的室内家具不应封死原本路径。

### 02 浅层教学

- **复用起点：** R02/R04/R05/R08，F05仅少量放在既有补给点旁。
- **需自建网格：** 2–3块松软面团坡/丘、1组面筋须（稀疏/密集变体）、气孔与呼吸孔各1组可辨识孔口。水源用1片水面，保留现有地形和孔洞落点。
- **需自建/派生材质：** 浅层暖米色地表；教学水源青绿水面；面筋叶片/须体普通材质。源水不是黄油瀑布，颜色和表面表达应可区分。
- **VFX：** 至多1套小气泡点缀，首轮可静态。呼吸孔开闭造型与动画机制分开交付，未确定机制前不承诺计时玩法。
- **落地核对：** Demo九节点顺序保持；Demo第2面粉(210,343.3)与独立面粉实体(200,233.3)不合并。气孔(173.3,300)是可选近道，呼吸孔(180,156.7)是另一处孔。整体图中的池塘数量不视为新资源点清单。

### 03 活跃发酵与黄油瀑布

- **复用起点：** R02/R03/R07/R08；现有SoStylized岩块可作背衬，不必在主视角继续表现为普通碎岩。
- **需自建网格：** 2–3个鼓胀/多孔崖模块，3段瀑布流片、1片潭、1条溪流，1组干化破壁外观与两侧封边。孔洞型远景高塔只是可选天际线模块，不能自动成为可攀爬路线。
- **需自建/派生材质：** 面团崖面；厚重黄油流体1主材质+不同流速实例；必要的浅潭边缘遮罩。先让静态形体、高光和颜色成立，再加流动。
- **VFX：** 最小1套落水接触泡沫/微粒；气泡可复用浅层方案并换色。避免用大量粒子掩盖流片与潭面接缝。
- **落地核对：** 顶(123.3,160，水面约15.85m)→潭(143.3,201.7，约0.65m)→溪末破壁口(143.3,233.3，约0.2m)必须相连。保留三次落差和唯一破壁口；图里拱洞和瀑布台阶不能增加绕开边界的新路。

### 04 酵母高地

- **复用起点：** R03/R07/R08负责尺度、背衬和地面；不需要Fantastic整栋建筑。
- **需自建网格：** 1组原创酵母囊/发芽面团（大/中/小三级变体）、1个特殊菌株、2种菌丝封边段。可先用R03占位，再决定图中气泡与有机上冠的最终轮廓。
- **需自建/派生材质：** 暖色囊体、低饱和青绿/薄膜光泽、轻微发光点各一个简单方向；优先保证与玩家相同画面下的明度层级。
- **VFX：** 最小1套低密度漂浮孢子；上冠/囊体微动可后置。发光不是整片地表全亮。
- **落地核对：** 唯一哨戒狭缝(96.7,132)保持；资源(100,106.7)与两酵母(83.3,93.3)/(60,66.7)按原路线保留。较大上冠与下部菌柄分件；不重用用户已排除的商业Mushroom包，也不因图中出现更多角色而新增敌人点。

### 05 霉菌废墟与深渊

- **复用起点：** R02/R04/R05/R07 + F07/F08/F09，F10仅作少量生活残件。
- **需自建网格：** 基地面团墙的2种破败变体、1组腐败孔群切面、深渊大孔环与坍塌孔边缘各1组、2种贴地菌丝、1个干化面团块/压力板外观。木桥继续用现有走道模块，不按概念图重新决定桥跨度。
- **需自建/派生材质：** 面团基础上的霉斑/粉灰紫腐败变体，破面暗色，菌丝色；保持普通可行走地面与孔底的明度区别。
- **VFX：** 首轮至多1套孔底轻雾/稀疏孢子，不能用浓雾掩盖深渊边缘或缩窄玩家可见路径。
- **落地核对：** 废墟(333.3,166.7)、坍塌孔(350,213.3)、深渊(410,140)保持。压力板是(393.3,180)，既有桥体中心约(393.3,170)，不能混写。桥是可选近道；外围绕行必须存在。深渊主动交互进入，坍塌孔为陷阱，两者需视觉区分。原17块隐藏桥板仍承担碰撞，不能因换外观删除。

### 06 地下菌核

- **复用起点：** R05/R06/R03承担洞壁/祭坛/光囊的白盒尺寸；不需要Fantastic中世纪祭坛或宝箱。
- **需自建网格：** 2–3种有机壁面/拱体、独立洞顶与垂挂段、1组低矮菌核底座、菌核外壳与内发光体分件、1组小光囊/菌丝。图中外圈高台先作为不可达后景候选，不增加楼层关卡。
- **需自建/派生材质：** 地下紫灰面团、紫金内腔发光、菌丝/细囊体；让主菌核发光最强，资源次之，背景再弱一级。避免整场景依赖高Bloom才有造型。
- **VFX：** 最小1套低密度雾气与少量核心漂浮粒子；静态核体和灯光先成立，再考虑搏动。Boss行为、受击和战斗阶段不在这份美术组合中。
- **落地核对：** 地下Z=−60m；祭坛/Boss仍在(436.7,83.3)，活动范围约80×60m。两护卫(403.3,60)/(466.7,60)及活性菌种(453.3,106.7)即使概念图未画出，也不能漏掉。图中发光蛋形核心、台阶与四周拱洞为候选；不能据此新增入口或缩小战斗空地。洞顶/上墙分件，保持玩家和中庭可见。

## 建议制作顺序

1. **当前：先看V1图。** 收集对面团孔洞密度、基地圆顶、黄油颜色、酵母囊体、霉菌色与紫金菌核的视觉反馈。确定方向后再进入下面资产阶段，不以这份清单自动启动全图重做。
2. **做一个基地样板和一段地形样板。** 在保留原关卡的情况下，用主棚独立顶/墙、面团崖面、现有桌架验证比例、表面和固定相机；只需一组基础材质和少量低草。
3. **铺共享形体语言。** 统一地面、崖面、大孔与断面后，再做浅层气孔、发酵隆起与黄油连续水系。先检验路线封边和地形高差，再增加装饰。
4. **制作生态差异。** 原创酵母囊与面筋族 → 霉菌破败变体/孔群 → 地下壁顶和菌核。尽量复用基础面团材质参数、模块和同族角色造型，避免六区各建完全独立系统。
5. **最后加有限动效与画面润色。** 依次处理黄油接触、气泡/孢子、烟雾、少量核心动效；用原2.5D相机检查路径、交互焦点和渐隐，再记录实际截图、走路轨迹与保存重开结果。

每个阶段都应能交付“清楚的资产路径 + 独立网格/材质说明 + 当前固定镜头截图 + 与原JSON的核对记录”。AI图作为视觉目标候选，UE达到的实际效果必须另有现场证据；本文件没有宣称当前工程已复现V1。
