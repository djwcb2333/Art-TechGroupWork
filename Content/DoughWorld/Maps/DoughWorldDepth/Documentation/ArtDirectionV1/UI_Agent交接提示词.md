## 项目与世界观

这是UE 5.8.2中的风格化2.5D俯视游戏：一个位于面团内部的微观世界。核心视觉词是面团、面筋、酵母、发酵气泡、湿润孔隙、黄油和霉菌腐败。

主要群体为面团、酵母、霉菌；另有中立对象。UI应让玩家辨认这些身份及环境差异。不要自行把它们改成职业、属性或技能树，也不要将尚未确认的设定写成正式规则。

当前地图包含六区：

1. 基地稳定区：安全高地，奶油白、暖米色，面团主棚、工作台、储物维修设施。
2. 浅层面团区：环绕基地的教学区域，浅黄面团、面粉、水源、面筋须、气孔和起伏地表。
3. 活跃发酵区：西侧隆起区域，暖金黄、发酵气泡、酵母芽、黄油瀑布与浅溪。
4. 酵母生态区：西北高地，大型酵母菌落、伞状形体和活性菌株；其详细发光色与装饰语言仍在做概念探索。
5. 霉菌腐败区：东侧低地，灰紫、暗紫与灰绿作为候选强调色，菌丝、腐败孢核、废弃面团聚落、坍塌孔和深渊入口。
6. 世界深层：地下区域，紫灰底色与少量发光强调，菌丝、活性菌种、核心祭坛和腐败菌核相关场景。

游戏采用固定方向的俯视镜头，鼠标左键点击移动；Space跳跃；Shift沿角色朝向翻滚约4米，碰撞会提前结束移动。相机当前为透视、Pitch -50°、Yaw 45°、FOV 55°、相机臂2800cm。
