## 视觉方向

提取第一张参考的面团微观世界语汇，结合第二张参考的手绘场景层次：圆润的大形、温暖奶油色、柔和冷色阴影、少量气泡与发光，沿路保留清楚的活动地面。面筋、酵母、霉菌的形体属于同一个世界，而非各自混用不同风格的资产包。

## 从图到引擎的边界

这是**待反馈的美术方向稿**。概念镜头为了展示纵深采用较低的透视视角，并夸张了背景高差、地标体量和部分植被密度；这不等于要修改当前玩家固定相机，也不是精确的500米地图施工图。总览与场景图之间不保证像素级地理对应，路线和坐标仍以原JSON为准。

图中的小生物、食物、栏杆、灯、布棚和发光属于美术提案；没有因此新增NPC、交互、技能或资源规则。图中类似叶片的形体需要在建模时收敛成面筋须、芽体或菌落叶状片，避免变成普通森林草丛。酵母菌冠需要保留原设计的菌盖/菌柄分件，而不是引入已排除的Mushroom包。

后续先将选定场景的地形体量、建筑和主要材质做成样板，使用真实2.5D相机检查；再替换小道具和植被并扩展到其余区域。Fantastic Village可提供家具、箱桶、袋筐、面包、小车和木桥板；面团壳体、孔洞、菌落、黄油液体及地下菌核仍须按本项目定制。具体资产路径与拆分见ConceptToBuild.md。

当前UE地图保留已完成的VillagePass：原地图内30种网格、60件新摆件，终态检查与截图见上级VillagePass/README.md。本组概念图没有被自动当作定稿去重做整个关卡。
