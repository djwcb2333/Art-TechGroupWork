## 环境 Actor 使用

`ADepthEnvironmentActor` 自带 `SceneRoot`、`EnvironmentMesh` 和 `CameraFadeComponent`。`EnvironmentMesh` 默认有**组件标签** `CameraFade`。可直接放置此 C++ Actor，或为不同冠盖/屋顶创建其子蓝图。一个 Actor 对应一个较小的局部冠盖、洞顶块、屋顶或墙片；根场景组件让网格局部偏移与缩放独立于 Actor。

Python 可通过 `actor.get_editor_property('environment_mesh')` 和 `actor.get_editor_property('camera_fade_component')` 获取组件。给前者设置静态网格和已接线的渐隐材质，编辑器保存后，PIE BeginPlay 自动绑定。运行时换材质或换网格后调用 `refresh_fade_meshes()`。本组件只在游戏世界绑定动态材质，不会把 MID 保存进编辑器资源。

树干、地面、台缘、低矮草和安全边界不应使用该 Actor 或此标签。带屋顶和地板的一体网格必须先拆成局部组件/资产，否则一体网格会整体变淡。普通 Actor 也可添加本组件，并给它需要渐隐的独立 `StaticMeshComponent` 贴标签。ISM 和 HISM 会记录警告并跳过，不能将本方案挂在整片实例化树林上。

组件不写相机、不修改碰撞、不重建导航。Actor 的网格碰撞由场景搭建时按资产决定，渐隐前后保持不变。

## 相机基线

现场基线来自根任务的 `DoughWorldV3/CameraBaseline.json`：透视，FOV 55，SpringArm 2800 cm，Pitch -50、Yaw 45、Roll 0，绝对旋转开启，碰撞测试关闭，相机位置延迟开启。本代码仅读取实际 PlayerCameraManager 的最终视图，不创建或改变相机。仍需在场景完成后检查实际映射是否存在缩放输入；本代码不会修改缩放映射。

地下场景洞顶高于玩家而低于固定相机时，按局部分块给洞顶贴标签；不对整块 Landscape 或整个地下大厅做全局透明化。

## 材质接线

不要直接修改 SoStylized 共享母材质。为本图创建专用副本或专用母材质，保持原 BaseColor、Normal、Roughness、WPO/风动等实际需要的连接。设置为 Masked；添加默认值 1 的标量参数 `CameraFade`：

`OpacityMask = 原 OpacityMask/叶片 Alpha × DitherTemporalAA(CameraFade)`

原来完全不透明的实体材质，原 Alpha 取 1。保留原材质合适的 Two Sided 和 Opacity Mask Clip Value 设置。已有树叶镂空 Alpha 不能被 CameraFade 覆盖。优先将渐隐接线放在材质最终透明度输出前，避免在纹理采样层丢失树叶边缘或孔洞。

每个受支持组件的每个槽创建独立 MID。当前参数 = 绑定时原参数 × 渐隐倍率，因此原参数 0.7 的槽遮挡时默认变为 0.14，离开后回到 0.7。默认 0.18 秒淡到 20%，离开后保持 0.2 秒，再用 0.3 秒恢复。参数名在绑定时缓存，运行中修改参数名需 Refresh。

缺少标量参数的槽输出警告并保持原样；仅检测到参数存在**不能证明它接到了可见性输出**。必须在真实抗锯齿/Nanite设置下分别截图 CameraFade=1 和 0.2，检查叶片原镂空、阴影、洞顶边缘及多层噪点，再运行控制器测试。阴影行为与视觉抖动仍由材质/渲染路径决定，不能凭 MID 数值通过就宣布美术效果通过。

## 交互目标接入

每次扫描始终读取实际本地 Pawn 的中心、头部、身体两侧和下半身，并独立检查每个遮挡组件的世界 AABB。多层遮挡会逐一处理，树冠无碰撞也可检测。AABB 是保守代理，大型不规则冠盖的空隙可能提前触发；用更小独立组件降低误判。

额外交互目标已实现真实位置跟随，接口如下：

- `AddProtectedTarget(TargetActor, LocalOffset, RadiusCm, HalfHeightCm)`：为本组件增加/更新一个目标。例：工作台 Actor，偏移 `(0,0,70)` cm，半径 30 cm，半高 40 cm。
- `RemoveProtectedTarget(TargetActor)`、`ClearProtectedTargets()`：撤销；渐隐经过保持时间后恢复。
- `AdditionalTargets`：可在关卡实例中直接配置明确的工作台等目标。每轮读取目标 Actor 当前变换，不使用冻结坐标。
- `SetInteractionTargetForWorld(WorldContext, TargetActor, LocalOffset, RadiusCm, HalfHeightCm)`：当玩家选中的交互目标改变时调用，一次性替换该世界所有本组件的额外目标列表；传空目标清除。该函数会清空原先的附加列表，不应与需要永久保留的列表混用。

默认仅保护距玩家 650 cm 内的额外目标；设 0 可关闭距离限制。无 Pawn 但相机有效时仍可保护已登记目标。隐藏、销毁、已失效的 Actor 不会参与判定。目标被销毁后自动删除失效引用。

当前工程是否有实际交互选择系统，尚未在本子任务确定；公共接口不是自动交互识别。如果尚无选择系统，关卡中明确的工作台目标可先配置到对应遮挡 Actor 的 `AdditionalTargets`，由后续程序再替换为选择事件。额外目标不能拿艺术参考图坐标或标签文字代替实际 Actor。

## 材质恢复与所有权

离开遮挡时仅恢复参数到原值；Deactivate、EndPlay、OnUnregister 时恢复原始材质对象。若别的系统在运行中替换了槽材质，本组件既不继续写新材质参数，也不在结束时覆盖它。Refresh 会先安全释放仍由自己拥有的材质，再绑定当前槽的有效材质。多次调用或同资产多 Actor 不共享 MID。

本实现为单本地玩家视图。多玩家/分屏没有每视图材质策略，不应把本实现当作已支持多人。

## 自动测试和专项画面验收

`validate_camera_fade_pie.py` 是可执行候选自动测试。进入 PIE 并让角色静止后执行脚本，再调用其中 `run(已接线测试材质路径, 报告绝对路径)`。新增 C++ `SpawnTransientValidationActor` 只允许在 PIE 世界创建带 RF_Transient 的测试对象；脚本不保存地图、不移动角色/相机，结束或发生异常时清理自建对象。

脚本使用实际玩家、实际相机、真实 MID 逐帧等待后检查：同资产独立 MID、两层遮挡同时淡出、原始非 1 参数恢复、无标签组件不参与、实际额外目标接口、取消目标恢复、第三方换材质不覆盖、Deactivate 恢复，以及相机位置/旋转/距离/FOV/投影/OrthoWidth 不变。报告有单独的渲染和碰撞验证布尔值，故意不会将这些未测项目冒充通过。若玩家移动或相机尚在延迟稳定中，相机不变检查会失败，需在静止后重测。

仍需人工/场景自动化补充：

| 检查 | 通过条件 |
|---|---|
| 树冠/树干 | 只淡冠盖，保留树干与叶片原镂空 |
| 洞顶/多层墙片 | 多层均处理，地面落差与危险边缘仍可读 |
| 实际工作台 | 屋顶淡出后操作对象可见，真实交互系统仍有效 |
| 墙片碰撞 | 淡出后依旧挡住角色；碰撞设置前后一致 |
| 沿墙沿走动 | 0.2 秒保持时间避免频繁开关闪烁 |
| 缺参材质/误贴 ISM | 明确日志且跳过，整片植被不透明化 |
| 停 PIE、切图、移除组件 | 原编辑器材质保持，无残留 MID 或半透明 |
| 固定相机 | 本图实际相机保持基线且输入不允许缩放 |
