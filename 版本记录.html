组员更新步骤（GitHub Desktop）

  1. UE停止Play，保存自己的修改并关闭编辑器。GitHub Desktop的Changes如有个人修改，先妥善提交/备份，不要Discard all changes。
  2. 左上Current repository选 Art-TechGroupWork，Current branch选 main。点顶部 Fetch origin；出现 Pull origin 后点击，等待源码及Git LFS资产全部下载。首次克隆仍用 File → Clone repository… → URL，填私有仓库地址并选择新的空目录。
  3. History确认本版标题和 v0.4.0-alpha.1。本版含C++与项目插件变更，旧本机DLL不能代替新编译。
  4. 使用匹配UE5.8.2与VS2022 C++工具/Windows SDK；右键本机 GDATtest.uproject → 显示更多选项 → Generate Visual Studio project files。打开生成的解决方案。
  5. Visual Studio顶部选 Development Editor / Win64，在解决方案资源管理器中右键 GDATtest → 生成；其Editor目标（GDATtestEditor）与DesertBuildingLab的Runtime/Editor模块随之编译。等待生成成功后打开工程。无需删除Content、Saved或个人存档。
  6. 默认标题地图是 DoughWorld/Maps/Gameplay/Levels/L_DWMainMenu_Showcase；旧Map1和新增测试图均保留。采集测试先打开上文GatheringTest再Play，停止后重置。
  7. 引擎插件 ModelContextProtocol、MCPClientToolset、AllToolsets 仍为既有依赖，不随仓库复制；若缺失先核对匹配安装，不自行禁用。内置ProceduralMeshComponent也必须可用。遇到LFS指针未落盘或编译错误，保留现场并反馈，不通过清空资源解决。
